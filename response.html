Connexion

Dans Omeka S : Utilisateurs → ton compte → Modifier → onglet « Clés d’API » → Nouvelle clé. Copie les deux valeurs ici.

Google vérifie qui tu es. Pour enregistrer dans Omeka, il faut aussi la clé API Omeka (onglet « Omeka (local) »).

Connexion GitHub : nécessite un petit serveur.

GitHub demande un « secret client » qu’on ne peut pas mettre dans une page publique. Il faut un service intermédiaire (par exemple une fonction serverless) qui échange le code GitHub contre un jeton, puis associe le compte GitHub à une clé Omeka.

Connexion CAS (compte université) : se fait côté Omeka S.

Le CAS de l’université redirige vers un serveur déclaré. On installe un module d’authentification CAS dans Omeka S : les étudiants se connectent alors à Omeka avec leur compte Paris 8, puis récupèrent leur clé API.
